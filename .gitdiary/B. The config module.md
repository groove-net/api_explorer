Let’s build the `config` module.

Since we set `CMAKE_CXX_STANDARD 17` in our build script, we can take advantage of modern C++17 features like `std::optional`. This is perfect for our use case because reading a file or finding a string might fail, and returning `std::nullopt` is a much cleaner, safer abstraction than returning an empty string or throwing an error.

To keep our project strictly zero-dependency right now (avoiding external libraries like `nlohmann/json` until absolutely necessary), we can use C++'s standard `<regex>` library to extract the URL. The `launchSettings.json` format generated by Visual Studio / the .NET CLI is highly predictable, making a targeted regex a lightweight and effective solution.

Here is the implementation mapped perfectly to your project structure.

### 1. The Public Interface

This goes in your `include/` directory. It defines the contract for any other module (like your `http` module later) that needs the base URL.

**Location: `include/config.hpp`**

```cpp
#ifndef CONFIG_HPP
#define CONFIG_HPP

#include <string>
#include <optional>

namespace config {
    // Parses launchSettings.json to find the base HTTP applicationUrl.
    // Returns std::nullopt if the file isn't found or the URL cannot be parsed.
    std::optional<std::string> get_base_url(const std::string& project_root_path);
}

#endif // CONFIG_HPP
```

### 2. The Implementation

This goes inside your `src/config/` directory. It handles the actual file reading and regex matching. If you point this at your authentication service directory (or any other WebAPI project), it will automatically append the `Properties/launchSettings.json` path and extract the target string.

**Location: `src/config/launch_settings.cpp`**

```cpp
#include "config.hpp"
#include <fstream>
#include <sstream>
#include <regex>
#include <iostream>

namespace config {

    std::optional<std::string> get_base_url(const std::string& project_root_path) {
        // Construct the expected path to the launch settings
        std::string file_path = project_root_path + "/Properties/launchSettings.json";
        
        std::ifstream file(file_path);
        if (!file.is_open()) {
            std::cerr << "[Config Error] Could not open: " << file_path << "\n";
            return std::nullopt;
        }

        // Read the entire file into a string
        std::stringstream buffer;
        buffer << file.rdbuf();
        std::string content = buffer.str();

        // Regex to find the "http" profile and extract its "applicationUrl"
        // It looks for: "http": { ... "applicationUrl": "MATCH_THIS" ... }
        // R"(...)" is a C++11 raw string literal, which saves us from escaping quotes wildly.
			  std::regex url_regex(
			      R"REGEX("http"\s*:\s*\{[^}]*"applicationUrl"\s*:\s*"([^"]+)")REGEX");
			  std::smatch match;

        if (std::regex_search(content, match, url_regex) && match.size() > 1) {
            // match[0] is the whole matched string, match[1] is the first capture group (our URL)
            return match.str(1);
        }

        std::cerr << "[Config Error] Could not find 'http' profile applicationUrl in " << file_path << "\n";
        return std::nullopt;
    }

}
```

### 3. The Local CMakeLists

This defines the module so your root orchestrator can link it.

**Location: `src/config/CMakeLists.txt`**

```makefile
# Define the config library
add_library(config STATIC
    launch_settings.cpp
)

# Expose the include directory so main.cpp (and others) can find config.hpp
target_include_directories(config PUBLIC
    ${CMAKE_SOURCE_DIR}/include
)
```

### 4. Testing It in `main.cpp`

Now, update your `src/main.cpp` to verify the module works. You can pass the path to your C# project as a hardcoded string for now (or eventually as a command-line argument `argv[1]`).

**Location: `src/main.cpp`** 

```cpp
#include "config.hpp"
#include <iostream>
#include <cstdlib>

int main() {
    std::cout << "Starting REST TUI Tester...\n" << std::endl;
    
	  // TODO: Replace this with the actual path to your C# WebAPI project root
	  std::string project_root = ".";

	  // 1. Get Base URL
	  auto base_url = config::get_base_url(project_root);
	  
	  if (base_url.has_value()) {
	    std::cout << "🌐 Base URL: " << base_url.value() << "\n";
	  } else {
	    std::cout << "⚠️ Could not find base URL. Check launchSettings.json.\n";
	  }

    return EXIT_SUCCESS;
}
```

Make sure your root `CMakeLists.txt` has `add_subdirectory(src/config)` and links `config` to your executable using `target_link_libraries(my_app PRIVATE config)`. 

```makefile
cmake_minimum_required(VERSION 3.15)

# -----------------------------
# Project Info

```
